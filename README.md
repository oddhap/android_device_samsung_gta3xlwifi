# LineageOS 21 for Samsung Galaxy Tab A 10.1 (2019)

Device tree for **SM-T510 / gta3xlwifi**. Android 14, ARM32 userspace and an
ARM64 Linux 4.4.302 kernel. This is an unofficial native ROM, without GApps.

Includes file-based encryption, the SM-T510 power backend, legacy networking
support and automatic compatibility-header updates for the matching TWRP.

- [ROM downloads](https://github.com/oddhap/android_build_samsung_gta3xlwifi/releases)
- [Kernel](https://github.com/oddhap/android_kernel_samsung_gta3xlwifi/tree/lineage-21.0)
- [Vendor](https://github.com/oddhap/android_vendor_samsung_gta3xlwifi/tree/lineage-21.0)
- [Platform patches and build tools](https://github.com/oddhap/android_build_samsung_gta3xlwifi/tree/lineage-21.0)
- [TWRP](https://github.com/oddhap/android_device_samsung_gta3xlwifi_twrp)

SM-T515 and other Galaxy Tab A models are not supported.
New device configuration is Apache-2.0; existing files retain their notices.
